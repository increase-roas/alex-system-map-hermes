# What the checks establish

Start with [the final acceptance closeout](FINAL_ACCEPTANCE.md), including the distinction between completed checks and later inconclusive repeat attempts.

This release is a **local foundation and Cursor handoff**. It is not a running React Flow application or a live audit of every service.

Use the latest machine-readable reports:

- `catalog-validation.json`: source accounting, IDs, references, source preservation, secret-pattern screening and spreadsheet checks.
- `schema-validation.json`: nine catalog contracts and a negative invalid-status case.
- `regeneration.json`: canonical JSON and Markdown bytes unchanged by rendering; generated spreadsheet cell content agrees.
- `independent-foundation-graph.json`: independent comparison with the original master, all original table cells and actual archived files.
- `independent-foundation-workflow.json`: independent behavioral checks, including the corrected dependency-edit recovery case.
- `independent-foundation-schemas.json`: independent schema/negative cases.
- `independent-foundation-catalog-cli.json`: actual bounded reads and invalid-input rejection.
- `independent-foundation-skills.json` and `independent-foundation-skill-exercise.json`: native structure, local links and fresh recovery interpretation. These do not prove automatic selection inside target apps.
- `independent-foundation-docs.json`: handoff consistency and file-browser requirements.
- `independent-foundation-pro-template.json`: independent supplied ZIP identity, named source paths, framework, license presence and read-only intake checks.
- `pro-template-intake.json`: supplied private Pro ZIP identity, source inventory and read-only inspection. No template code was run.

`workflow-final-tests.txt` supersedes the earlier nine-test `workflow-tests.txt`. Earlier proof files are retained as historical development evidence; they do not override newer checks. The reference engine's current test suite has 12 behavioral tests.

The package preserves all **2,377 original coverage records**, **198 overview entries**, **192 source tabs**, **294,002 compared populated source cells**, **1,009 archived source files**, and **59 explicit relationship records**. The final catalog contains **2,351 component records/pages**, including expanded inventory, navigation groups, plan reviews and unresolved references. Of the 32 added SDK/adoption review records, 30 are planned and two retain a recorded local closure; neither implies fleet proof.

The Braintrust screenshot and React Flow Pro ZIP are supplemental user inputs. They are not silently counted as part of the original 1,009-file archive.

Current-file viewing, file ↔ consumer navigation, browser accessibility, the local service's authentication, actual UI recovery and native target-runtime skill selection remain Cursor/application acceptance items. All hosting and Drive publication remain outside this local delivery; **local-only, Drive not updated**.
